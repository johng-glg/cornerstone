Step 0 — the four answers the build cannot get on its own

These buttons touch production. The Flow and timezone checks each create a real appointment on the notary's calendar. They are named “STEP0 TEST — do not attend”. Cancel them with the button at the bottom before you leave this page.

Held in memory only — never stored, never put in the URL bar. Every check sends it as a header. If STEP0_TOKEN is unset in Vercel, every check refuses to run.

0. Exchange an authorization code for a refresh token

Run this first. Until it does, there is no refresh token, and every check below refuses to run. Generate a Self Client code in the Zoho API Console, then paste it here.

The authorization code expires in minutes. Generate it and exchange it immediately — do not stop to copy anything else first. invalid_code almost always means it expired.

Change the accounts host only for a non-US data centre — .eu, .in, .com.au and so on. The request carries your client secret, so it is only ever sent to a known Zoho host.

Scopes for the Self Client
Bookings: zohobookings.data.CREATE — this one scope covers the read endpoints too; Fetch Services documents it for a GET.
Payments: confirm the exact strings in the API Console scope picker rather than guessing them. If combining Bookings and Payments scopes returns Invalid Scope, generate two separate codes from the same client credentials and exchange each one here — you will get two refresh tokens, which is what ZOHO_REFRESH_TOKEN and ZOHO_PAYMENTS_REFRESH_TOKEN expect.

1. Does the BlueNotary Flow fire on an API-created appointment?

If it does not and nobody checks, a paid client gets an appointment with no notarization session behind it. This is the one the spec says not to skip.

2. What zone does Zoho read from_time in?

Books at 11:00 while declaring a deliberately non-org zone, then reads it back. If Zoho ignores the timezone field, every signer outside the org zone books the wrong hour and nothing surfaces it until a customer complains.

3. How long does a payment session stay valid?

Sets the slot hold TTL. The hold must outlive the session, or a slow customer pays against a lapsed hold and turns into a refund and an ops alert.

4. Can Flow trigger on a status change to noshow?

Decides whether no-show refunds are event-driven or need a nightly sweep. Marks the appointment created by check 1, so run that first.

Clean up

Cancels the test appointment. Do this before you leave, every time. A stray STEP0 booking on a real calendar is exactly the mess this page exists to avoid.
